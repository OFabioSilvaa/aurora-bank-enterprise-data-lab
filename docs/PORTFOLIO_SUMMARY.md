# Resumo para portfólio

## Nome do projeto

Aurora Bank Enterprise Data Lab

## Descrição curta

Projeto fictício de Engenharia de Dados e Analytics que simula um banco digital/múltiplo com dados sintéticos, arquitetura em camadas, PostgreSQL, DuckDB, SQL analítico, Cliente 360, KPIs executivos e regras de negócio bancário.

## Objetivo

Criar um ambiente prático e realista para estudar SQL, análise de dados, BI, engenharia de dados e modelagem analítica no setor financeiro.

## Stack

- PostgreSQL
- DuckDB
- Python
- Pandas
- SQL
- VSCode
- pgAdmin
- Excel / Power BI

## Principais entregas

- Data warehouse fictício bancário;
- Cliente 360 V8;
- DWs de contratação, portabilidade, CRM, canais digitais, cobrança e churn;
- KPIs executivos;
- quality checks;
- primeira demanda simulada de gestor;
- documentação de arquitetura e dicionário rápido.

## Aprendizados demonstrados

- modelagem em camadas;
- criação de tabelas analíticas;
- migração DuckDB para PostgreSQL;
- SQL aplicado a regras bancárias;
- criação de KPIs;
- análise de risco, churn, cobrança e crédito;
- organização de projeto para GitHub.
